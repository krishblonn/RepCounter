RepCounter App Map

Visual architecture and data flow guide for your browser-based AI workout companion.

Dashboard & UI (`index.html`)

Handles user navigation between the Dashboard, Active Workout HUD, Error Warning Overlay, and Set Summary modal using Tailwind CSS.

Vision Engine (`src/pose.js`)

Streams webcam frames into MediaPipe Pose via CDN, renders skeleton overlays on HTML5 Canvas, and triggers warnings on poor lighting or lost person.

Angle & State Machine (`src/counter.js`)

Calculates 3-point joint angles, applies temporal moving average smoothing, and runs the finite state machine ("up" / "down") to count reps reliably.

Persistence (`src/storage.js`)

Saves completed set statistics (reps, duration, accuracy) to browser LocalStorage so past workout history survives page refreshes.

✨ Built end-to-end with zero backend servers, complete local privacy, and modular ES6 architecture.
